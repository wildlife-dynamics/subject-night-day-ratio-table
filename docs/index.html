Subject night day table

Tabulates, night by night, how much faster each subject in an EarthRanger subject group moves at night than by day. The night/day ratio compares movement speed in darkness with speed in daylight: 1 is balanced, above 1 the subject moves faster at night, below 1 it moves faster by day.

What it does

StepWhat it does
Set Workflow DetailsName and description shown on the dashboard.
Connect to EarthRangerThe EarthRanger site to read from.
Set Time RangeThe period to analyse.
Set GroupersHow the table is split: per subject, per time period or per spatial region. Leave empty for one view.
Subject GroupFetches the location fixes of the subject group picked from the drop-down, for the time range.
Process RelocationsCleans the fixes and drops known bad coordinates (0,0 / 1,1 / 180,90).
Classify Is NightFlags each fix as night when the sun is below the horizon at its location and time.
Persist RelocationsSaves the classified fixes as relocations.geoparquet.
Trajectory Segment FilterJoins the fixes into track segments, dropping segments outside the Trajectory Segment Filter limits.
Persist TrajectoriesSaves the track segments as trajectories.geoparquet.
Map Trajectory ColumnsRenames the subject and day/night columns (e.g. subject_name, is_night) and drops unused patrol columns.
Sort Night Day ValuesOrders the segments by their day/night flag.
Extract Date from Segment StartAdds a segment_start_date column: the date each segment starts on (kept in the data; the ratio dates each night itself).
Split GroupsOne table of segments per group from Set Groupers.
Summarize Night Day DfComputes the night/day ratio for each subject on each solar day (local noon to local noon, so one whole night), dated by that night's local midnight (2 decimal places).
Exclude null values from night_day_ratioKeeps only rows with a ratio above 0, dropping solar days that couldn't be scored.
Persist Night Day DfSaves each group's nightly ratios as a CSV file.
Map Night Day DFRenames the columns to Date, Subject Name and Night Day Ratio for the table.
Draw Night Day TableDraws the nightly ratios as a table, one row per subject per night.
Persist Night Day Table as HTMLSaves each table as an HTML file.
Create Table Widget Single ViewWraps each table as a Night Day Ratio Table widget.
Merge Widget ViewsCombines the per-group tables into one widget, so the dashboard filter switches between them.
Gather DashboardCollects the table widget into the dashboard.

What it produces

OutputDescription
relocations.geoparquetThe cleaned location fixes, each with an is_night flag.
trajectories.geoparquetThe track segments built from those fixes.
One CSV per groupThe night/day ratio for each subject on each solar day, with columns subject_name, solar_date and night_day_ratio. Days that couldn't be scored are left out.
One HTML table per groupAs shown on the dashboard.
DashboardA Night Day Ratio Table; with groupers set, the dashboard filter switches between groups.
