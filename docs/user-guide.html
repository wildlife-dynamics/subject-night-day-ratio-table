User Guide

How to load Subject night day table, connect its data source and fill in its settings.

1. Load the workflow

In the workflow runner, add a new template using this repository's URL, then select Subject night day table from the templates list.

2. Data sources

  • Access to an EarthRanger data source, set up as a connection

3. Settings

The run form asks for these. Fields with a default can be left as they are; fields marked Advanced are collapsed.

4. Run it and find the results

The workflow writes its files to the results folder the runner gives it (ECOSCOPE_WORKFLOWS_RESULTS), and shows its dashboard when it finishes.

OutputDescription
relocations.geoparquetThe cleaned location fixes, each with an is_night flag.
trajectories.geoparquetThe track segments built from those fixes.
One CSV per groupThe night/day ratio for each subject on each solar day, with columns subject_name, solar_date and night_day_ratio. Days that couldn't be scored are left out.
One HTML table per groupAs shown on the dashboard.
DashboardA Night Day Ratio Table; with groupers set, the dashboard filter switches between groups.

A ratio of 1 means equal speed by night and day, above 1 faster at night, below 1 faster by day. Each row is one night: a solar day runs from local noon to local noon and is dated by the local midnight in it, so the night of 3–4 May is listed as 4 May. Days without more than 1 hour of observed data in both daylight and darkness, or with no movement by night or by day, are left out (see the Technical Guide).
